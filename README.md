# Al Ameen Collective MVP

## Overview
A modern B2C e-commerce platform for premium unstitched fabrics in Pakistan. Uses a unique WhatsApp-first ordering workflow.

## Project Structure
This repository contains two completely separate applications:
- `/backend`: Node.js, Express, TypeScript, Prisma, PostgreSQL (Supabase)
- `/frontend`: React 19, Vite, TypeScript, Tailwind CSS, shadcn/ui

## Getting Started

### Backend Setup
1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env` and fill in Supabase credentials
4. `npm run dev` to start the server

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev` to start the Vite server
